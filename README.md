# ESP-Sensors

Проект для Waveshare ESP32-C6-LCD-1.47 с подключением датчиков SHT45 (температура/влажность) и BMP581 (давление/температура). Данные отображаются на встроенном LCD дисплее 1.47" с использованием графической библиотеки LVGL v8.

## Оборудование

- **Плата**: Waveshare ESP32-C6-LCD-1.47
- **Дисплей**: ST7789, 172x320, 16-bit color
- **Датчик SHT45**: Температура и влажность (I2C)
- **Датчик BMP581**: Давление и температура (SPI)

## Подключение

### Дисплей (ST7789)
| Пин | ESP32-C6 |
|-----|----------|
| MOSI | GPIO6 |
| SCLK | GPIO7 |
| CS | GPIO14 |
| DC | GPIO15 |
| RST | GPIO21 |
| BL | GPIO22 |

### SHT45 (I2C)
| Пин | ESP32-C6 |
|-----|----------|
| SDA | GPIO4 |
| SCL | GPIO5 |

### BMP581 (SPI)
| Пин | ESP32-C6 |
|-----|----------|
| CS | GPIO3 |
| MISO | GPIO8 |
| SCK | GPIO9 |

## Особенности

- **LVGL v8**: Графическая библиотека для отображения данных
- **Отключены Wi-Fi и Bluetooth**: Для экономии памяти и освобождения пинов
- **Яркость дисплея**: 50% (для предотвращения перегрева)
- **Обновление данных**: Каждые 2 секунды

## Сборка и прошивка

### Требования
- PlatformIO IDE в VS Code
- ESP-IDF v5.3.1 или новее

### Шаги
1. Откройте проект в VS Code
2. Установите зависимости: `pio run`
3. Загрузите на плату: `pio run --target upload`
4. Откройте монитор порта: `pio device monitor`

## Использование

После прошивки на дисплее отобразится:
- Заголовок "Sensor Data"
- Температура от SHT45 (зелёный)
- Влажность от SHT45 (синий)
- Давление от BMP581 (оранжевый)

Данные обновляются автоматически каждые 2 секунды.
